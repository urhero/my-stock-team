# 📊 my-stock-team — 나만의 AI 주식 리서치 팀

**종목 이름 하나만 입력하면, AI 애널리스트 5명이 협업해서 리서치 리포트(PPT 파일)까지 만들어 주는 도구입니다.**

> ⚠️ 이 도구는 **무료 공개 데이터 기반 학습용**입니다. 투자 권유가 아니며, "사라/팔아라" 같은 판단은 절대 하지 않습니다. **최종 투자 판단은 항상 사람의 몫입니다.**

---

## 🤔 이게 뭔가요?

[Claude Code](https://claude.com/claude-code)라는 AI 프로그램에 설치하는 **확장 기능(플러그인)**입니다.

설치하면 AI 안에 가상의 리서치 팀이 생깁니다:

| 팀원 | 하는 일 |
|------|---------|
| 📑 **펀더멘털 애널리스트** | 전자공시(DART)에서 회사의 매출·이익 같은 재무 정보를 가져와 3년 치 흐름을 정리합니다 |
| 📈 **시장·기술 애널리스트** | 최근 6개월 주가와 거래량을 보고 추세를 정리합니다 |
| 📰 **뉴스·심리 애널리스트** | 최근 뉴스를 검색해 중요한 이슈와 시장 분위기를 요약합니다 |
| 🛡️ **리스크 매니저** | 위 세 명의 결과를 종합해 "조심해야 할 점 3가지"를 뽑습니다 |
| ✅ **검증 애널리스트** | 완성된 리포트에 틀린 숫자나 빠진 내용이 없는지 검사합니다 |

그리고 마지막에 **보기 좋게 디자인된 PPT 리포트**를 자동으로 만들어 줍니다.

---

## 🧰 시작 전에 필요한 것

1. **Claude Code 설치** — [공식 안내](https://claude.com/claude-code)를 따라 설치하세요. (AI와 대화하며 일을 시키는 프로그램입니다)
2. **Python 설치** — [python.org](https://www.python.org/downloads/)에서 설치하세요. (PPT 생성에 사용되는 무료 프로그램입니다. 이미 설치돼 있다면 건너뛰세요)
3. **Windows 추천** — PPT의 한글 글꼴(맑은 고딕)이 Windows에 기본 포함되어 있습니다. Mac/Linux도 가능하지만 글꼴 설정이 한 번 더 필요합니다(아래 FAQ 참고).

---

## 📥 설치 방법 (따라만 하세요)

### 1단계. 보조 프로그램 설치

컴퓨터에서 **터미널**(Windows는 시작 메뉴에서 "PowerShell" 검색)을 열고, 아래 한 줄을 복사해 붙여넣고 Enter:

```
pip install python-pptx matplotlib finance-datareader pykrx opendartreader
```

> 💡 이건 주가 조회, 공시 조회, PPT 생성에 필요한 무료 도구 모음을 한 번에 설치하는 명령입니다.

### 2단계. Claude Code에 플러그인 설치

Claude Code를 실행하고, 대화창에 아래 두 줄을 차례로 입력:

```
/plugin marketplace add urhero/my-stock-team
/plugin install my-stock-team@my-stock-team
```

### 3단계. (선택) 전자공시 API 키 만들기 — 재무 분석을 쓰려면

> 🔑 "API 키"는 일종의 **무료 회원증**입니다. 정부 전자공시 사이트(DART)가 "누가 데이터를 가져가는지" 확인하는 용도예요. 발급도 사용도 무료입니다.

1. [DART 오픈API 사이트](https://opendart.fss.or.kr) 접속 → 회원가입 → **인증키 신청**
2. 발급받은 키(영문+숫자 40자)를 복사
3. 분석 작업을 할 폴더 안에 `.env` 라는 이름의 텍스트 파일을 만들고, 안에 이렇게 한 줄 작성:

```
DART_API_KEY=여기에_발급받은_키_붙여넣기
```

> ⚠️ **이 키는 비밀번호처럼 다루세요.** 남에게 공유하거나 인터넷에 올리면 안 됩니다.
> 💡 키가 없어도 됩니다! 그 경우 재무 분석만 "확인 불가"로 표시되고, 주가·뉴스·리스크 분석은 모두 정상 동작합니다.

## 🚀 사용 방법

Claude Code 대화창에 이렇게 입력하면 끝:

```
/stock-report 삼성전자
```

그러면 자동으로 이렇게 진행됩니다:

```
종목 확인 → 애널리스트 3명 동시 분석 → 리스크 점검 → 리포트 작성 → 검증 → PPT 생성
```

결과물은 `reports/` 폴더에 저장됩니다:
- `reports/삼성전자.md` — 글로 된 리포트
- `reports/삼성전자.pptx` — 디자인된 PPT 리포트 (7장 슬라이드)

### 일부만 물어볼 수도 있어요

전체 리포트가 필요 없으면 그냥 말로 부탁하세요:

- *"삼성전자 재무만 봐줘"*
- *"SK하이닉스 요즘 뉴스 분위기 어때?"*
- *"현대차 주가 추세만 정리해줘"*
- *"이 리포트 검증해줘"*

## 🎨 PPT 리포트는 이렇게 생겼어요

7장 구성: **표지 → 종목 개요 → 재무 요약 → 가격·추세 → 뉴스·심리 → 리스크 → 한 줄 종합**

- 차분한 금융 리포트 디자인 (다크 표지 + 노란색 포인트)
- 모든 숫자 옆에 **출처와 날짜**가 붙습니다
- 글꼴은 맑은 고딕으로 고정 — 한글이 깨지지 않습니다

## 🔒 안전장치 (자동으로 지켜집니다)

이 도구는 다음 규칙을 **스스로 강제**합니다:

- ✅ 출처 없는 숫자는 리포트에 싣지 않습니다
- ✅ 데이터를 못 구하면 지어내지 않고 **"확인 불가"**라고 정직하게 씁니다
- ✅ 확인 안 된 뉴스·루머는 **"미확인"**으로 표시합니다
- 🚫 "매수 추천", "목표가 OO원" 같은 투자 단정 표현은 **시스템이 차단**합니다 (그런 문구가 있으면 PPT 생성 자체가 멈춥니다)
- 📝 모든 리포트 끝에 학습용 면책 문구가 자동으로 들어갑니다

## ❓ 자주 묻는 질문

**Q. 돈이 드나요?**
플러그인과 데이터(DART, 주가)는 무료입니다. Claude Code 자체의 이용 요금은 별도입니다.

**Q. 실시간 주가인가요?**
아니요. 하루 단위의 지연된 시세입니다. 단타용이 아니라 리서치용입니다.

**Q. 이 리포트만 보고 투자해도 되나요?**
**안 됩니다.** 이 도구는 판단에 필요한 자료를 정리해 줄 뿐입니다. 숫자의 출처를 직접 확인하고, 투자 결정은 본인이 하세요.

**Q. Mac/Linux인데요?**
`skills/report-pptx/build_pptx.py` 파일 상단의 `KFONT`와 `MPL_FONT` 값을 컴퓨터에 설치된 한글 글꼴 이름(예: "Apple SD Gothic Neo")으로 바꾸면 됩니다.

**Q. 미국 주식도 되나요?**
한국 주식(KRX) 중심으로 만들어졌습니다. 미국 주식은 재무(DART)·수급(pykrx) 파트가 "확인 불가"로 빠질 수 있습니다.
