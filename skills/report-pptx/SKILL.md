# report-pptx

`reports/{종목명}.md`(종목 리서치 마크다운)를 읽어 **디자인된 PPTX 리포트**를 만든다.

- **입력**: `reports/{종목명}.md` (현재 작업 디렉터리 기준)
- **출력**: `reports/{종목명}.pptx`
- **렌더링/디자인/가드레일**: 이 스킬 디렉터리의 `build_pptx.py`가 전담(아래 절차에서 호출).
- **의존성**: `python-pptx`, `matplotlib` (네트워크 접근 없음). 한글 폰트 '맑은 고딕'(Windows 기본) 필요.

## 디자인·규칙 (빌더가 강제 — 변경 불가)

- 슬라이드 순서(고정): **표지 → 종목 개요 → 재무 요약 → 가격·추세 → 뉴스·심리 → 리스크 → 한 줄 종합**
- 증권사 리포트 톤: **다크 차콜 표지**(EQUITY RESEARCH 키커 + 옐로우 액센트 밴드), 본문은 그레이 화이트
- 포인트색 **KB 옐로우 `#FFBC00`** — 섹션 번호(01~06)·타이틀 언더라인·KPI 카드 탑바·차트 하이라이트에만 절제 사용
- 공통 크롬: 모든 본문 슬라이드에 **푸터(종목·작성일·페이지 번호)**
- 재무 표: 다크 헤더 + 숫자 우측 정렬 + 교대 행 배경
- 가격 슬라이드: **KPI 카드**(최대 4장) + 차트(그레이 바, 현재가만 옐로우 하이라이트) + 우측 추세 코멘트
- 한글 폰트 **맑은 고딕** 하나로 고정(글자 깨짐 방지)
- 모든 수치 옆 **(출처/기준일)** 표기 — 출처 없는 숫자는 싣지 않음
- **매수/매도·목표가 단정 표현 금지** — 위반 시 빌드가 `ValueError`로 중단됨
- 표가 슬라이드 밖으로 잘리지 않게 — 행이 넘치면 빌더가 자동 축소

## 절차

### 1. 입력 확인
사용자가 종목명을 줬으면 `reports/{종목명}.md`를 읽는다. 종목명이 모호하면 `reports/`의 `.md` 목록을 보여주고 확정한다. 파일이 없으면 멈추고 알린다.

### 2. 마크다운 → 구조화 JSON 추출
`.md` 내용을 아래 스키마(JSON)로 매핑한다. **추출 단계에서 가드레일을 먼저 적용**한다:

- **출처 없는 수치는 제외**한다. 본문/표/지표에서 출처·기준일이 확인되지 않는 숫자는 싣지 않는다. 재무표는 표 전체에 `source` 하나를 단다.
- **매수/매도·목표가·비중확대 등 단정 표현을 제거**하고 판단 근거 서술로 바꾼다. (`순매수`, `매도 물량` 같은 사실 서술어는 허용)
- 7개 섹션을 항상 채운다. 해당 정보가 .md에 없으면 빈 배열/빈 문자열로 둔다(빌더가 "데이터 없음" 처리).

```json
{
  "stock_name": "삼성전자",
  "ticker": "005930",
  "market": "KRX",
  "as_of_date": "2026-06-11",
  "overview": ["한 줄 개요 항목", "..."],
  "financials": {
    "headers": ["지표", "FY2023", "FY2024", "FY2025"],
    "rows": [["매출액(조원)", "258.9", "300.9", "333.6"], ["..."]],
    "source": "DART, 2025 사업보고서"
  },
  "price": {
    "metrics": [
      {"label": "현재가", "value": "298,500원", "source": "FinanceDataReader, 2026-06-11"}
    ],
    "chart": {
      "title": "주요 가격 지표",
      "orientation": "h",
      "labels": ["현재가", "MA20", "MA60", "52주최고", "52주최저"],
      "values": [298500, 305300, 242877, 370000, 56900],
      "unit": "원",
      "source": "FinanceDataReader, 2026-06-11"
    },
    "comment": ["추세 코멘트 한 줄", "..."]
  },
  "news": {
    "items": ["이슈 한 줄 (출처: 매체, YYYY-MM-DD)", "..."],
    "sentiment": "종합 긍정 — 근거 한 줄"
  },
  "risk": {
    "items": ["리스크 1", "리스크 2", "리스크 3"],
    "monitoring": ["모니터링 포인트", "..."]
  },
  "conclusion": "한 줄 종합 — 판단 근거까지만, 매수/매도 단정 없음"
}
```

추출 가이드:
- `as_of_date`는 .md의 기준일/작성일. 없으면 오늘 날짜.
- `financials.rows`는 최근 3개년 핵심 지표 위주(매출·영업이익·당기순이익 등). 너무 많으면 빌더가 12행으로 자른다.
- `price.chart.values`는 **숫자(단위 없는 원시값)**. 라벨/단위는 별도 필드. 차트로 만들 적절한 수치(가격 레벨 또는 변동률)가 .md에 없으면 `chart`를 생략하고 `metrics`만 채운다.
- `price.metrics`의 각 항목은 `source` 필수(없으면 빌더가 드롭).
- `risk.items`는 핵심 리스크 위주(권장 3개).

### 3. JSON 저장 후 빌더 실행
추출한 JSON을 임시 파일로 저장하고 빌더를 호출한다. **빌더 경로는 이 스킬의 베이스 디렉터리(스킬 호출 시 안내되는 "Base directory for this skill") 아래의 `build_pptx.py`**다:

```bash
python "<스킬 베이스 디렉터리>/build_pptx.py" --input "<temp>.json" --output "reports/{종목명}.pptx"
```

### 4. 결과 보고
생성된 `reports/{종목명}.pptx` 경로를 알린다. 빌더가 `ValueError`(가드레일 위반/출처 누락)로 멈추면, 해당 문구를 수정해 2단계부터 다시 한다.

## 참고
- 빌더는 `python-pptx`, `matplotlib`(Agg)만 사용하며 네트워크에 접근하지 않는다. 입력은 `.md` 하나뿐이다.
- 디자인 토큰(색·폰트·여백·표 상한 `MAX_TABLE_ROWS`)은 `build_pptx.py` 상단 상수로 관리된다.
